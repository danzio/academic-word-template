# Научная работа СПбГЭУ — шаблон Word

Шаблон Microsoft Word (`.dotm`) для подготовки диссертаций, научных статей, отчётов и других академических материалов.

Шаблон включает настроенные стили оформления, автоматическую нумерацию объектов, перекрёстные ссылки, работу с формулами и собственную вкладку **«Научная работа»** на ленте Word.

## Основное оформление

Основной стиль текста — **`ГОСТ`**:

- Times New Roman, 14 pt;
- выравнивание по ширине;
- абзацный отступ 1,25 см;
- межстрочный интервал 1,5;
- интервалы до/после абзаца — 0 pt.

Стиль используется как основной рабочий стиль документа.

### Заголовки

Используются встроенные стили Word с настроенной многоуровневой нумерацией:

- `Заголовок 1` — главы: `1.`, `2.`, `3.`;
- `Заголовок 2` — параграфы: `1.1.`, `1.2.`;
- `Заголовок 3` — подпункты: `1.1.1.`; в содержание не включаются;
- `Структурный элемент` — ненумерованные элементы типа `Введение`, `Заключение`, `Список литературы`;
- `Заголовок оглавления` — название `Содержание`.

## Содержание

Автоматическое содержание строится по:

- `Заголовок 1` — уровень 1;
- `Заголовок 2` — уровень 2;
- `Структурный элемент` — уровень 1.

`Заголовок 3` в содержание не включается.

Стили `Оглавление 1` и `Оглавление 2` настроены отдельно.

## Рисунки

Стиль подписи — **`Название рисунка`**.

Формат:

> Рисунок 1.1 – Название рисунка

После подписи автоматически создаётся:

> Источник:

а после источника — новый абзац стилем `ГОСТ`.

Нумерация адаптивная:

- при наличии нумерованных глав: `Рисунок 1.1`, `Рисунок 1.2`, `Рисунок 2.1`;
- без нумерованных глав: `Рисунок 1`, `Рисунок 2`.

При изменении структуры документа нумерация перестраивается через **«Обновить все поля»**.

### Перекрёстные ссылки на рисунки

Можно выбрать рисунок и форму ссылки:

- `рисунок 1.1`;
- `рисунке 1.1`;
- `рисунка 1.1`;
- `рис. 1.1`;
- только `1.1`.

Номер остаётся живой перекрёстной ссылкой и обновляется автоматически.

## Таблицы

Используются стили:

- `Название таблицы` — название над таблицей;
- `Заголовок таблицы` — первая строка таблицы;
- `Текст таблицы` — основной текст;
- `Источник` — строка после таблицы.

Формат:

> Таблица 1.1 – Название таблицы

После таблицы автоматически создаётся:

> Источник:

и следующий абзац стилем `ГОСТ`.

Макрос **«Оформить таблицу»**:

- применяет стиль `Текст таблицы`;
- применяет `Заголовок таблицы` к первой строке;
- делает первую строку повторяющейся на последующих страницах;
- выравнивает её по вертикали по центру.

Нумерация также адаптируется к наличию/отсутствию глав.

### Перекрёстные ссылки на таблицы

Доступны варианты:

- `таблица 1.1`;
- `таблице 1.1`;
- `таблицы 1.1`;
- `табл. 1.1`;
- только `1.1`.

## Формулы

Формулы создаются штатным редактором формул Word, без MathType.

Используются стили:

- `Формула`;
- `Номер формулы`.

Макрос создаёт невидимую техническую таблицу `1 × 3`:

- формула располагается строго по центру страницы;
- номер — по правому краю.

При вставке появляется placeholder:

> Введите формулу

Нумерация адаптивная:

- с главами: `(1.1)`, `(1.2)`, `(2.1)`;
- без глав: `(1)`, `(2)`, `(3)`.

Для каждой формулы создаётся техническая закладка `Formula_XXXX`, благодаря которой работают живые перекрёстные ссылки.

В тексте ссылка оформляется, например:

> согласно формуле (2.1)

## Список литературы

Используется стиль **`Список литературы`**:

- Times New Roman, 14 pt;
- выравнивание по ширине;
- одинарный межстрочный интервал;
- интервалы до/после — 0 pt;
- выступ — 0,75 см;
- табуляция — 0,75 см.

Настройка рассчитана на совместную работу с Zotero и нумерованным библиографическим списком.

## Сноски

Используется встроенный стиль **`Текст сноски`**:

- Times New Roman, 10 pt;
- выравнивание по ширине;
- одинарный интервал;
- без абзацного отступа;
- интервалы до/после — 0 pt.

## Вкладка «Научная работа»

Шаблон содержит собственную вкладку RibbonX.

### Структура
- **Вставить содержание**
- **Обновить содержание**
- **Обновить все поля**

### Рисунки
- **Подпись рисунка**
- **Ссылка на рисунок**

### Таблицы
- **Название таблицы**
- **Ссылка на таблицу**
- **Оформить таблицу**

### Формулы
- **Вставить формулу**
- **Ссылка на формулу**

### Сервис
- **Источник**
- **Дата → словами**
- **Дата → цифрами**
- **Нормализовать тире**

## Сервисные функции

### Нормализация тире

Макрос приводит конструкции с пробелами к среднему тире:

```text
" - " → " – "
" — " → " – "
```

Дефисы внутри слов не затрагиваются.

### Преобразование дат

Поддерживается преобразование:

```text
04.05.2026
↓
04 мая 2026 г.
```

и обратно:

```text
04 мая 2026 г.
↓
04.05.2026
```

Если выделен фрагмент текста, обрабатывается только он. Если выделения нет, Word предлагает обработать весь документ.

Некорректные календарные даты не преобразуются.

## Адаптивная нумерация

Шаблон автоматически определяет наличие **нумерованного `Заголовка 1`**.

Это позволяет использовать один `.dotm` как для диссертации, так и для статьи:

| Документ с главами | Документ без глав |
|---|---|
| Рисунок 2.1 | Рисунок 1 |
| Таблица 2.3 | Таблица 3 |
| Формула (2.1) | Формула (1) |

После добавления или удаления структуры необходимо нажать:

> **Научная работа → Обновить все поля**

Номера объектов и перекрёстные ссылки будут синхронизированы.

## Перенос шаблона

Все стили, VBA-макросы и вкладка RibbonX находятся внутри `.dotm`.

Поэтому для переноса на другой компьютер достаточно перенести сам файл шаблона.

Рекомендуется поместить его в папку пользовательских шаблонов Word и при необходимости разрешить выполнение макросов / добавить папку в надёжные расположения Office.

## Резервное копирование

Перед существенными изменениями VBA, стилей или RibbonX рекомендуется сохранять резервную копию `.dotm`.

Например:

```text
Научная работа СПбГЭУ v1.0.dotm
Научная работа СПбГЭУ v1.1.dotm
```

## Примечание

Шаблон создавался как практический инструмент для научной работы. Он автоматизирует оформление, но не отменяет проверку требований конкретного диссертационного совета, журнала, кафедры или издательства.

> **Известная особенность:** иконка «Нормализовать тире» технически является `GroupTableTools`. Не задавайте вопросов.
